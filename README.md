# Smart Zombies (Minecraft 1.20.1, Forge 47.3.0)

Умные зомби: поле зрения (по телу, без «мотания головой»), слух (шаги, выстрелы с учётом оружия и глушителя,
взрывы, ломание блоков), память, зов других зомби, блуждание к местам, где игрок проводит время,
ломание слабых блоков.

Все настройки: `config/smartzombies-common.toml` (появляется после первого запуска).

Команды (нужны читы / права оператора):
- `/smartzombies debug` включает или выключает отладку: частицы над зомби и подсказки в чате
- `/smartzombies noise <радиус>` делает шум на вашем месте, чтобы проверить слух
- `/smartzombies status` показывает, что делают ближайшие зомби

Сборка: GitHub -> вкладка Actions -> build -> Artifacts -> smartzombies-jar.
